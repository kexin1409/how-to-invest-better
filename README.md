## 这是什么

一本以**周金涛《人生财富靠康波：涛动周期论》（中信出版集团，2024）**为核心来源的结构化整理。原书是周金涛（中信建投证券原首席经济学家）的周期论文集与演讲合集，信息密度极高但散落在报告、演讲和访谈里。这本书做的是：

- 把康波（约 50～60 年长波）、三周期嵌套、大类资产配置、房地产周期等主题，拆成 **186 条可检索的条目**；
- 每条沿用系列统一的「性价比」框架：**成本**（钱/时间/毅力）× **收益** × **证据等级**（A/B/C）× **性价比**，并针对投资主题新增 **风险** 档（低/中/高）；
- 所有条目注明出自原书；书中判断有兑现也有落空的地方，如实标注「争议」。

**不构成投资建议。** 所有判断都是周金涛的历史观点，不是对未来价格的承诺。

## 页面特性

- 单文件、零第三方依赖，生成的 HTML 无外部资源，双击即可离线阅读
- 全文搜索 + 高亮；按章节、性价比、证据等级、**风险**、花钱、花时间、要毅力多维筛选（章节单选、其余多选，条件可叠加）
- 「争议」「待核实」开关；筛选状态写入 URL，可分享带筛选的链接
- 明暗双主题（跟随系统），移动端自适应，支持打印
- 正文内「第 X 节第 Y 条」交叉引用可点击跳转

## 证据分级与性价比口径

- **证据等级**：A = 书中有具体数字、回测或统计规律支撑；B = 有较实在论据但偏定性；C = 作者观点框架或共识性判断。
- **性价比**：由「收益量级 + 三项成本（钱/时间/毅力）」合成的作者判断，与证据等级无关。「一般」不等于不该做。
- **风险档**（本书特有）：低 = 主要亏时间或小额成本；中 = 可能亏损本金一部分；高 = 可能大幅回撤。讲周期框架的书里，凡是据此下注的条目，多为中/高风险。

## 内容与来源

- 12 节 186 条；证据 A 24 / B 69 / C 93；性价比 极高 108 / 高 65 / 一般 13；标注争议 6 条。
- 所有条目整理自周金涛《人生财富靠康波：涛动周期论》（中信出版集团，2024）；书中涉及的康德拉季耶夫、熊彼特、罗斯托、范杜因、库兹涅茨等理论均转述自原书的文献综述。
- 周金涛的部分著名判断（如 2016 年触底反弹、2018 年全球 risk off）事后得到验证，也有未兑现的（如 2017 年中美资产「全线回落」、中国房价 2017—2018 年进入下行）。第 7 节和第 11 节对此有诚实记录。

## 目录结构

```
book/           # 正文（12 个 Markdown 文件，每节一个）
build.py        # 生成单文件 HTML 阅读页（零依赖）
make_pdf.py     # 生成 PDF（reportlab）

```

```bash
python build.py -o index.html      # 生成阅读页
python make_pdf.py -o how-to-invest-better.pdf   # 生成 PDF
node tools/test_page.js            # 跑页面回归测试（13 项断言）
```
